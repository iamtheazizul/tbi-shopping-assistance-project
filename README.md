# TBI Shopping Assistance App

This is a mocked frontend prototype to demonstrate the UI/user flow for the shopping assistance app built for ENGS 89/90.

## Getting Started

1. Run `npm install`
2. Run `./node_modules/.bin/vite` (use this instead of `npm run dev` if you get a "vite not found" error)
3. Open `http://localhost:5173/` in your browser

## Notes

- This is a UI prototype — data is mocked, no backend connected yet
- Built with React + TypeScript + Vite + Tailwind CSS
